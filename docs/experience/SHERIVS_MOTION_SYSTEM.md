# Sherivs Motion System

Version target: **V1**.

Motion explains state. It does not perform.

| Moment | Treatment |
| --- | --- |
| Public page | No entrance choreography. Content is present |
| Hover and focus | Color and underline. Focus ring uses the signal color |
| Press | Existing button active state in the app kit |
| Route change | Existing `RouteProgressBar` |
| Loading | Existing skeletons and the index "Loading…" line |
| Offline | Existing offline banner in the authenticated shell |
| Reduced motion | Global CSS: animation and transition duration collapse to 0.01ms |

Not built, because they would not represent a live backend state on the public site: AI thinking loops, particle fields, mission progress theatre, parallax.

Inside the product, existing assistant typing dots remain. They must only play while a response is actually pending. This pass did not re-audit every assistant for that invariant; it is a remaining check.

Durations in the token contract: 120ms, 200ms, 360ms. Public CSS does not use the spring curve.
