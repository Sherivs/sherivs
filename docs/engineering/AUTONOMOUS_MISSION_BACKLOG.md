## Status definitions

- **NOT STARTED:** no implementation attempt.
- **DISCOVERED:** backed by audit evidence; implementation not assigned.
- **IN PROGRESS:** a bounded implementation/review is active.
- **BLOCKED:** requires a dependency or external fact/authorization not available.
- **READY FOR REVIEW:** implementation exists but is not approved.
- **VERIFIED:** required tests and independent review passed; does not imply deployment.
- **CLOSED:** scope explicitly removed from the approved release.

Do not close a mission because its report was written or a branch was created. Update priority/status only when the evidence and launch scope justify it.
