# Sherivs Responsive System

Design independently at 360 / 390 / 430 / 768 / 1024 / 1280 / 1440 / 1600 / 1920 / 2560+.

## Public

Desktop: lockup + inline nav + account actions.  
Mobile: lockup + request access + disclosure menu. Do not shrink the desktop mega-structure.

Homepage uses a 12-column editorial grid that collapses to a single measure.

## Application

Sidebar collapsible; mobile uses swipe-to-open + bottom nav when the runtime declares destinations. Command search is icon-only on small screens.

## Data

Wide tables sit in horizontal scroll wrappers (`.uos-scroll-x`). Prefer definition lists on public; keep operational tables in the app with sticky headers.
