# Sherivs Responsive System

**Version-target:** ACTIVE-V1

Breakpoints (px): 360, 390, 430, 768, 1024, 1280, 1440, 1600, 1920, 2560+.

| Viewport | Public | Application |
|---|---|---|
| 360–430 | Display type scale down; stacked planes; sheet nav | Bottom nav where declared; tables scroll; 44px targets |
| 768 | Two-column interior sections begin | Sidebar overlay |
| 1024+ | Primary nav visible; plane stack beside hero | Sidebar + header |
| 1440–2560 | Max content 72rem; unused width is negative space, not stretched cards | Same |

Do not shrink a desktop dashboard. Mobile IA is bottom nav + sheets, not a squeezed sidebar.
