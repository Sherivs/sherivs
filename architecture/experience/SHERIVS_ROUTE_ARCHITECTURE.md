# Sherivs Route Architecture

TanStack Router file routes under `frontend/src/routes/`. `routeTree.gen.ts` is generated by the build/dev server and is not edited by hand.

## Public tree — pathless group `(site)`

`(site)/route.tsx` wraps children in `PublicShell` (skip link, header, footer). Public marketing pages share it; the root `/` renders itself with the same shell for non-tenant visitors.

| Path | File | Status |
| --- | --- | --- |
| `/` | `routes/index.tsx` | LIVE (Sherivs home; tenant host / `?school=` renders the organization site) |
| `/platform` | `(site)/platform.index.tsx` | LIVE |
| `/platform/$slug` (reality, memory, intelligence, ai-workforce, missions, governance, integrations) | `(site)/platform.$slug.tsx` | LIVE; unknown slug -> `notFound()` |
| `/solutions`, `/solutions/organizations`, `/solutions/education` | `(site)/solutions.*.tsx` | LIVE |
| `/security`, `/pricing`, `/status`, `/legal/accessibility` | `(site)/*.tsx` | LIVE |
| `/resources`, `/resources/$kind`, `/resources/$kind/$slug`, `/resources/rss.xml` | `(site)/resources.*` | LIVE shell; empty state, noindex, not in sitemap while nothing is published |
| `/coregrid` | `(site)/coregrid.tsx` | 301 -> `/` |
| `/sitemap.xml`, `/robots.txt` | `sitemap[.]xml.ts`, `public/robots.txt` | LIVE; derived from the registry |

## Deferred (no route exists, by design)

`/about`, `/company`, `/careers`, `/contact`, `/request-demo`, `/enterprise`, `/solutions/enterprise`, `/solutions/operations`, `/solutions/ai-workforce`, `/legal/privacy`, `/legal/terms`, `/legal/cookies` (a pre-existing `/privacy` route is untouched and not claimed as counsel-approved Sherivs text). Reasons are recorded in `public-routes.ts` (no approved content, no counsel-approved legal text, no real intake channel, or duplication). A conformance test asserts no route module exists for a DEFERRED entry.

## Authentication and organization

| Path | Notes |
| --- | --- |
| `/auth`, `/login`, `/reset-password` | Pre-existing. Login landing is not defaulted to Scholar. |
| `/_authenticated/*` | Pre-existing authenticated portals (admin, teacher, student, parent, bursar, driver, hq, messages, notifications, settings, runtime). Legacy visual layer. |
| `/command-centre/provision` | Provisioning wizard moved off the public root; authenticated. |

## Internal (Sherivs operators) — separate boundary

| Path | Notes |
| --- | --- |
| `/super-admin/architecture` | Was `/platform`. `super_admin` gated, `robots.txt` Disallow. |
| `/super-admin/organization` | Was `/platform/org`. Same. |

Not linked from any customer navigation. Authorization is enforced server-side; the route gate is defense in depth only.

## Redirect and compatibility rules

* Moved paths: old internal `/platform` and `/platform/org` were repurposed; references in `lib/platform.ts`, `contexts/app-context.tsx`, `lib/tenant.ts`, `runtime.tsx`, `marketplace.tsx`, `reality.$class.tsx`, `command-centre.tsx` and four tests were updated after searching for usages.
* Technical route/DB identifiers containing `coregrid` are unchanged.
