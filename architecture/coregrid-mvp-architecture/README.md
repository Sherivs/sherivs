# CoreGrid V1 MVP Architecture

Authoritative architecture area for **CoreGrid V1** — the first commercially usable
execution layer of the CoreGrid institutional computing architecture, under the
Constitution **V5.3 MVP execution profile** (Parts 0–85).

## Authority chain

1. `../COREGRID_V53_DIRECTIVE_RECONCILIATION.json` — Part 110 reconciliation adopting V5.3
2. V5.1 Parts 0–109 + V5.2 Parts 110–141 — preserved master architectural directives
3. `COREGRID-V1.md` — this area's constitution (V1 capability envelope and boundary law)
4. `foundation/` — machine-readable V1 artifacts (scope lock, capability catalog, gap
   register, master implementation plan, launch criteria, blockers)
5. `../future/` — frozen future architecture register (V2/V3/UNASSIGNED — preserved, never deleted)

## The law in one line

**BUILD COREGRID V1 — not a demo, not V5.1/V5.2 wholesale.** Implement only the V1
organizational capability envelope. Freeze, never delete, the future. Every capability
carries an explicit version classification; unknown scope stops work until classified.

## V1 identity (V5.3 Parts 1–2, 75)

> AI-NATIVE ORGANIZATIONAL COMPUTING PLATFORM — one platform from which many
> organizational domains (schools, restaurants, hotels, pharmacies, clinics, retail,
> services, NGOs, …) are instantiated through configuration, not separate codebases.

V1 deliberately excludes: device/IoT integration (V2 FROZEN), geospatial, geophysics,
geology, mining, satellite, agricultural-satellite, biological, chemical, environmental
sensing, physical digital twins, simulation, planetary intelligence (V3 FROZEN), and
civilization-scale / autonomous-engineering self-hosting (FUTURE-UNASSIGNED).
