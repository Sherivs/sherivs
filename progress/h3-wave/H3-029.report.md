## Implemented

`tests/unit/h3-029-memory-retrieval-authz.test.ts` — an adversarial, offline,
pure-TypeScript proof suite (39 tests, 5 describes) demonstrating that memory
retrieval is authorization-gated with NO bypass path across every retrieval
surface of the memory domain (all modules imported READ-ONLY, never modified):

- `frontend/src/lib/memory/memory-store.ts` — durable memory tier
  (`retrieveMemory`, `retrieveMemoryThroughWorkerSession`,
  `openWorkerMemorySession`, `terminateWorkerMemorySession`);
- `frontend/src/lib/context/memory-scope-enforcement.ts` — the
  session/mission/long-term scope gate (H3-018's module, consumed read-only
  as directed);
- `frontend/src/lib/agent-memory.ts` — the phase-07 consumer-side interface
  (`readMemory`).

Proven invariants (Constitution §15/§16/§31, AGENTS §5/§6/§8):

1. **Unauthenticated retrieval denied** — empty/whitespace identity, missing
   tenant, missing/undeclared scope, and identities outside the declared
   scope's `actorScope` are all denied before any record is evaluated
   (fail-closed, J-017), each attempt audited. The scope gate denies an empty
   principal (`principal_not_in_scope`); the consumer surface returns nothing
   for an empty agent id (deny-by-default on identity emptiness).
2. **Cross-tenant denied at every layer** — precondition denial, a
   defense-in-depth per-record `tenant_mismatch` exclusion (a foreign-tenant
   record is NEVER returned), worker-session binding tenant denial
   (retrieval AND session-open), scope-gate `cross_tenant`, and the consumer
   tenant filter.
3. **Revoked/expired principals denied** — suspended worker definition cannot
   open a session; a terminated session's live handles are permanently
   invalidated; an expired session-tier scope denies (`scope_expired`);
   stale records (`stale`), bi-temporally expired records
   (`validity_expired`), and records whose required permission the principal
   lacks (`permission_denied` — proven to be an authorization gate by the
   permission-held counterpart) are all excluded. The consumer surface
   denies above the agent's classification ceiling and denies undeclared
   categories.
4. **Scope expansion unreachable through retrieval paths** — granted AND
   denied retrievals mutate no scope and no record; retrieval is pure (the
   input store is never mutated — no side-effect channel); a denied attempt
   leaves the scope gate's revision and expansion ledger untouched; a domain
   denied by retrieval stays uncovered and widens ONLY via an explicit,
   audited, typed expansion act (revision 1 → 2, ledger record); a session
   cannot read beyond its binding's namespaces or readable tiers even though
   the underlying scope covers more; a session cannot redirect retrieval to
   another declared scope; a forged session handle has no authority (the
   registry is the only source of truth); the binding is FROZEN (mutation
   attempt throws).
5. **No leakage beyond the authorized scope** — returned records are exactly
   the authorized set with every withheld record a typed, audited exclusion
   (`exceeds_declared_sensitivity`, `outside_declared_scope`,
   `tenant_mismatch`); the item budget excludes surplus records
   (`item_budget`), never silently truncates; TEXTUAL OVERLAP between the
   retrieval purpose and a record's content cannot rescue an unauthorized
   record — there is no similarity path to a grant (G-015 no-vector-only);
   the access record is complete (`returnedRecordIds` == returned records,
   every record covered by grant-or-exclusion); denied retrievals still
   append their audit record; exclusion records carry reasons and metadata
   but never the withheld record's content; the worker-session path
   preserves the full leak-freedom contract (results ⊆ binding, all
   withholdings audited).

## Security Validation

- Mandatory Constitution §31 matrix: Tenant A cannot access Tenant B
  (proven at 4 layers); User A cannot access User B (identity/actorScope and
  session-binding identity gates); agents cannot exceed permissions
  (permission gate + frozen bindings + registry-resolved authority); expired
  access fails (scope expiry, validity expiry, staleness); revoked access
  fails (suspended lifecycle, terminated sessions, forged handles).
- Fail-closed semantics verified on every gate; every denial carries a typed
  reason and an audit record (nothing denied silently).
- Strict TypeScript: no `any`, no `z.any()`; typed fixtures and narrowing
  helpers; only branded-type assertions (`agentId()`/`tenantId()`) and one
  `as unknown as { namespaces: string[] }` cast used to prove the frozen
  binding throws on tampering.
