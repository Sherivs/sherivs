## Implemented

Typed, Zod-validated, fail-closed, domain-neutral CONTRACT module for the phase-46 substrate surface, scoped to what the phase-46 kernel contract owns — twin FEDERATION (agreement, cross-tenant shared-state exchange, relationship mapping, federation governance). Phase 16 keeps twin identity/state; phase 08 keeps authorization decisions; this surface composes with platform primitives read-only (§16 decision vocabulary imported as a type from `frontend/src/lib/identity.ts`).

Structural encodings (not just comments):

- **§10 twin admission.** `federatedTwinRefSchema` structurally requires identity, owner, tenant, current-state digest, history reference, capabilities (≥1) and governing policies (≥1) before a twin may enter a federation. An incomplete twin is unparsable. State travels by digest, never by value.
- **A twin is NOT a permission bypass — three structural walls:**
  1. `federationAgreementSchema.accessGrant: z.literal("none")` — an agreement that grants access cannot be expressed or parsed;
  2. `sharedStateEnvelopeSchema.authority: z.literal("mirror")` — shared state is a mirror, never an authority to act;
  3. `evaluateTwinDataAccessRequest()` — the ONLY function mapping twin data to an access outcome — returns a typed refusal (`TWIN_PRESENCE_IS_NOT_A_GRANT`) for every attempt; the verdict type has no `granted: true` branch. `TWIN_PRESENCE_GRANTS` is the empty set.
- **Federation by agreement, not convenience.** Tenant-spanning invariant (parties from different tenants; same-tenant pairing refused `not_a_federation`); mandatory bounded validity window (`invalid_window`); exact field-path allowlist with NO prefix semantics (`isFieldPathInScope`); exchange outside scope/state/expiry DENIED; minimization (payload by digest only); `restricted` classification must be `redacted` (`redaction_violation`); every envelope attributed to the agreement that permitted it.
- **Governance (§16 vocabulary).** `federationGate()`: unknown actions DENY; `record_agreement` REQUIRE_APPROVAL without evidence (cross-jurisdiction named); `exchange_state` ALLOW only for ACTIVE + unexpired + exact in-scope path; `widen_shared_scope` ALWAYS ESCALATE (never automatic, even with evidence); `revoke_federation` REQUIRE_APPROVAL then ALLOW (severing stays easy).
- **Lifecycle.** PROPOSED→APPROVED→ACTIVE⇄SUSPENDED→REVOKED; revocation is terminal — a revoked federation never resurrects.
- **§11 relationships.** `twinRelationshipSchema` requires provenance, ownership on both sides, the authorizing agreement and explained confidence — no anonymous cross-twin linkage.
- **Fail-closed parsing.** All parsers return typed `TwinParseResult<T>` with structured issues; a failed parse never yields a partial artifact.

Laws honored: pure module — no I/O, no vendor imports, no wall-clock reads (every instant supplied), no secrets, no sibling H3 imports, no `any`/`z.any`, no new dependencies, no domain vocabulary (J-037; neutral twin classes: entity/process/environment/infrastructure/intelligence/comprehensive).
