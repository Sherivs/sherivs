## Implemented

`frontend/src/lib/knowledge-graph/contracts.ts` — the typed, Zod-validated, fail-closed contract surface for the phase-48 substrate (per `architecture/phase-48-civilization-knowledge-graph.md`, phase-completion-status row 48: ARCHITECTURE_DEFINED, and the phase-48 kernel contract):

- **AGENTS §11 made structural:** every relationship schema mandates `provenance`, `ownership`, `authorization` and `confidence` as required fields (strictObject). An edge missing any of the four does not parse and can never be published, traversed or disclosed. Traversed-edge projections carry all four fields by construction.
- **An edge is not a permission (kernel boundary):** traversal (`evaluateTraversal`) and entity reads (`authorizedEntityView`) demand a presented, valid authorization gate and deny by default (`no_gate_presented`, `gate_malformed`, `gate_expired`, `decision_not_permitted`, tenant/principal/purpose mismatches, retired/over-sensitive roots). Filtering is at query time; stored edges keep their governance fields; every exclusion is counted and surfaced (`excluded` counters), nothing drops silently.
- **Cross-tenant invisibility (AGENTS §13):** federated edges are structurally invalid without both `federationRef` and `approvalRef` (`cross-tenant-edge-creation` is approval-gated per the kernel contract); tenant-scoped edges with out-of-tenant endpoints are excluded as `foreign_tenant`; federated edges traverse only under a matching gate `federationRefs` entry, else `cross_tenant_unfederated`.
- **Canonical truth separation (AGENTS §9):** edges are `asserted` or `inferred`; inferred edges must cite `inferenceMethodRef` and asserted edges may not carry one; confidence is banded (tier must match the numeric band: confirmed ≥ 0.95, high ≥ 0.75, medium ≥ 0.4, unknown < 0.4); high/confirmed edges must cite evidence; the graph carries payload references only — entity views and traversal node metadata never expose `payloadRefs`.
- **Governed lifecycle:** `proposed → published → superseded|retracted`, strict chain, revision-carrying transitions (`applyEdgeLifecycleTransition`), retraction requires an approval reference (semantic `missing_approval` denial, shape-level parse — the platform forgetting-act pattern), retraction is terminal and makes edges unreachable in traversal.
- **Governed publication:** `publishRelationship` enforces the confidence publish floor (0.5), endpoint existence/retirement, and tenant-scoped endpoint tenancy; `publishRelationship` returns the published edge, never mutates input.
- **Fail-closed everywhere:** all parsers return typed `ContractResult`s, never throw; traversal defensively re-parses candidate edges and entities so malformed inputs can never leak into a result (`malformed_edge` / absent-from-index).
- **Composition (read-only only):** binds to `frontend/src/lib/kernel/phase-contracts/phase-48-knowledge-graph.ts` (posture composed from its `id`/`capabilities.owns`/`boundary.statement`/`asi.autonomy.requiresApprovalFor`) and reuses the platform `ContextSensitivity` vocabulary from `frontend/src/lib/context-assembly.ts`. No sibling H3 module imported; no new dependencies; no I/O, no vendor imports, no wall-clock sampling (time always injected as ISO-8601).

## Security Validation

- **Deny-by-default posture:** default decision `deny`; every read surface fails closed without a valid gate; there is no gate-free path to nodes, edges or entity metadata.
- **Tenant isolation (AGENTS §13):** gate tenant must match request/root/entity tenant; tenant-scoped edges with any out-of-tenant endpoint are excluded; cross-tenant visibility requires structural `federationRef` + `approvalRef` AND a matching gate federation reference. Tested both directions (excluded without agreement, included only with it).
- **An edge is not a permission:** the contract's boundary statement is asserted in tests; edges carry references, never payloads; entity views expose metadata only (key-set assertions prove `payloadRefs` never appears).
- **Secrets:** the module handles references only; no secret-shaped fields, no logging, no network, no credential paths. Nothing to leak by construction.
- **AI trust (AGENTS §9/§21):** inferred edges are labelled derived, must cite a method, and confidence bands forbid overstating certainty; approval gates cross-tenant edge creation (kernel `requiresApprovalFor` asserted in posture tests).
- **No security weakening:** no existing test, policy, migration or workflow file was read-modified or executed; existing suites untouched.
- **Type safety:** strict TypeScript, no `any`, no `z.any()`; all denial reasons are exhaustive typed unions; `tsc --strict` clean on both files.
