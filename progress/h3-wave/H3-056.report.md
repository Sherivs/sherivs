## Implemented

- **Typed contract surface for the phase-36 substrate** (all pure, Zod-validated, `strictObject`):
  - Memory scope kinds (personal/organizational/institutional/agent/domain/civilization/reality — phase §3), record kinds (phase §17–§21), knowledge abstraction ladder data→information→knowledge→understanding→wisdom→intelligence (phase §5) with rank ordering, validation states + evidence levels (phase §7/§46), lifecycle states and a strict transition table (phase §16/§152).
  - **Provenance (phase §8/§156; AGENTS §12)**: origin kind, creator, origin ref, ordered transformation/validation history, and a declared `aiGenerated` flag.
  - **Confidence/validation invariants**: validated knowledge MUST cite evidence (level other than `none`, ≥1 ref, confidence ≥ 0.5); retracted knowledge MUST carry a retraction reason (and only retracted records may carry one).
  - **Retention (phase §28/§152)**: bounded-by-default — `bounded` requires `expiresAt` (after `createdAt`); `unbounded` is only legitimate with an approval reference (retention-policy-change is approval-gated per the kernel phase contract).
  - **Recall authorization gate (L-T-015 posture; AGENTS §16/§19)**: every recall and record read requires a presented gate carrying decision, principal, tenant, scope, purpose, sensitivity ceiling, directives, decided/expires instants, authority and trace. Fail-closed rules: no eternal gates; `redact` requires ≥1 directive (and only `redact` may carry directives).
  - **`evaluateRecallRequest`** — deny-by-default with typed reasons (`no_gate_presented`, `gate_malformed`, `gate_expired`, `decision_not_permitted`, `tenant_mismatch`, `scope_mismatch`, `principal_mismatch`, `purpose_mismatch`, `request_malformed`); ALLOW returns a bounded scope, never content; REDACT returns directives only.
  - **`authorizedMemoryView`** — the single content-opening surface; binds gate→caller (`principalRef`/`purposeRef` must match the gate), refuses expunged, retracted, not-stored and above-ceiling records; every denial typed. No bypass path exists in the module.
  - **`evaluateAiDisclosure` (AGENTS §19)**: blocks unless the pipeline is complete (identity, authorization, classification, purpose allowed, minimized, redacted) AND a valid gate is presented AND classification ≤ gate ceiling AND record sensitivity ≤ classification; retracted/expunged records are never disclosable. The disclosed payload is **metadata-only by construction** (record id, abstraction level, validation state, ai-context ref) — the contract never returns raw content to a model surface.
  - **Knowledge revision / version control (phase §15)**: revisions carry reason, contributor, previous/new lifecycle; expunging revisions require an approval ref; `applyLifecycleTransition` verifies transition legality, record-id and previous-state consistency and returns a fresh record.
  - **Governed forgetting (phase §29/§152)**: `executeForgettingAct` is approval-gated (`missing_approval` typed denial), idempotent (`already_expunged`), structurally strips content (`"summary" in record === false`), stamps `expungedAt`, emits a content-free tombstone, and the expunged record is then unreachable through every read surface and non-transitionable.
  - **Fail-closed parsers** for scope keys, records, gates, requests, pipelines, revisions and acts — `safeParse`-based, typed failures, never throw on hostile input.
- **Composition (read-only platform primitives only)**: binds to the phase-36 kernel contract `frontend/src/lib/kernel/phase-contracts/phase-36-memory-knowledge.ts` (boundary statement, capability, `requiresApprovalFor` incl. `forgetting-execution`, `retention-policy-change`, `cross-tenant-recall`) into an exported `MEMORY_KNOWLEDGE_CONTRACT_POSTURE` (default decision `deny`, recall `authorization-gated`); reuses the platform `ContextSensitivity` vocabulary from `context-assembly` instead of redefining it. No sibling H3 module imported; no vendor imports; no I/O; time always injected.
- **Neutrality (J-037)**: module lives in its own subdirectory `frontend/src/lib/memory-knowledge/`; grep-verified zero education/domain vocabulary in both files; new files placed outside the neutrality-guard-scanned root-level/`kernel/phase-contracts/` paths.

## Security Validation

- **L-T-015 (memory retrieval authorization bypass)**: encoded as structural posture — there is no exported read surface that returns content without a valid gate; malformed/missing/expired/mismatched/non-permitting gates all fail closed to typed reasons; the record-level view additionally binds the gate to the presenting caller, so a gate cannot be replayed across principals or purposes.
- **AGENTS §19 (AI privacy)**: disclosure requires the full ordered pipeline layered on a valid gate; disclosed payload is minimized metadata only.
- **Deny-by-default & fail-closed** throughout; no `any`, no `z.any()`; `strictObject` everywhere; unknown/extra fields rejected.
- **Secrets**: module stores references only (`principalRef`, `purposeRef`, `traceId`, `approvalRef`) — no credential or secret values, nothing logged; no secrets printed during this mission.
- **No canonical access**: no database, no network, no migrations touched; no git commands run (coordinator owns staging).

## Known Risks

- The contract is a typed substrate surface only — enforcement lives in server-side layers (phase 08 authorization; `cg_memory_*` RLS policies). This module is one layer, never the only one (Constitution §17).
- Retention expiry is expressed as an instant comparison at enforcement time; a scheduled reaper that actually purges expired records is out of this contract's scope (owner: phase-36 runtime).
- `refField` reference pattern is deliberately conservative (≤200 chars); if upstream reference formats diverge, parsers will fail closed rather than accept — a future widening must remain explicit and reviewed.
- Verifier team G-074 will test this module adversarially read-only; any hardening they surface should be landed by the coordinator.
