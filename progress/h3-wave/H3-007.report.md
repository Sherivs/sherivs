## Implemented

`tests/failure/h3-007-recovery-chaos.test.ts` — a failure-path chaos battery for recovery tooling consuming the backup-manifest contract (`frontend/src/lib/reliability/backup-manifest.ts`, owned by A-003, imported READ-ONLY). A typed test-local "recovery gate" harness (validate → lifetime check → coverage check → restore-or-abort, built only on the contract's exported schema and pure queries) drives hostile manifests through four failure classes:

1. **Corrupt manifest** — non-object inputs; each required field dropped (all are load-bearing); unsupported/missing `schemaVersion` (typed `schema_version_unsupported`); absolute or upward-traversing `storageRef` (path-escape smuggling refused); empty entry sets; empty scope; hostile entry payloads (bad `byteSize`, empty ids, unknown kinds).
2. **Missing / broken checksum** — absent entry and manifest-level checksums; non-hex/uppercase/empty digests; wrong digest length per algorithm (typed `checksum_digest_length`); algorithm/digest-length mismatch; unknown algorithms; `isWellFormedChecksum` agreement.
3. **Expired backup set** — expired (typed `expired`), strict boundary (`expiresAtMs === now` is already expired), no premature refusal 1 ms before expiry, future-captured (`not_yet_valid`), retention-window overrun (`retention_window_exceeded`), inverted lifetime (`lifetime_inverted`), and THE TRAP: shape-only validation without a clock reports an expired manifest as ok — the gate refuses to run without an injected clock.
4. **Partial scope / tenant coverage** — a `partial: true` manifest parses (explicit is honest) but can never drive a full-tenant restore; zero-tenant coverage does not parse; duplicate tenants (`duplicate_tenant`); duplicate entry ids (`duplicate_entry`); duplicate scope families (`scope_family_duplicate`); restores requested for uncovered tenants abort.

Plus fail-closed hygiene: all structural issues are reported together (never truncated to the first), and the gate never throws on any hostile input — every scenario resolves to a typed verdict.
