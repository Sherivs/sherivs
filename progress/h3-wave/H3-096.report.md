2. **FINDING (low, latent containment gap):** `runIsolatedSimulation` passes `startingState` to the model by reference without defensive cloning; a careless model could mutate the caller's production state object in place. The namespace boundary still holds (result is always `simulation`), but input immutability is not structurally guaranteed. Not asserted as a guarantee for that reason.
3. **Note (by design, but worth knowing):** the `crossTenantGranted` input to `authorizeTwinAccess` is an unscoped boolean — no expiry, purpose, or operation binding. The grant itself must come from a governed path; this module does not (and cannot) verify the grant's provenance.
