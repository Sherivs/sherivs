## Implemented

`frontend/src/lib/zero-trust-defense/contracts.ts` — a typed, fail-closed, domain-neutral CONTRACT module for the phase-42 substrate surface (untrusted input classification → defense verdicts → escalation paths). Pure: no I/O, no persistence, no vendor imports (only `zod`), no wall-clock reads, no secrets, offline-testable, strict TypeScript (no `any`, no `z.any()`).

- **Untrusted by default (AGENTS §5; phase-42 §1/§4/§298).** `UNTRUSTED_BY_DEFAULT_POSTURE` constant; every input carries an `inputOrigin` (`unverified_client` / `autonomous_agent` / `machine_pipeline` / `human_session`) — origin informs classification, never grants passage. **Self-classification is structurally rejected**: a non-human subject cannot classify its own input (`classifiedBy === subjectRef` fails parse).
- **Untrusted input classification.** `inputClassificationSchema` — outcomes `benign` / `suspect` / `hostile` / `indeterminate`; anything above `benign` requires ≥ 1 named `signal`; `indeterminate` requires an `indeterminateReason` (`signals_conflicting` / `signals_insufficient`) and is the fail-closed class — never a silent pass. Strict objects, bounded text, bounded signal sets, snake_case identifier pattern.
- **Defense verdicts over the §16 decision vocabulary, structurally minus ALLOW.** `DECISION_VOCABULARY` encodes the full AGENTS §16 vocabulary (`allow`, `deny`, `redact`, `escalate`, `require_approval`) as a platform reference; `defenseVerdictSchema` is that vocabulary minus `allow` — the surface cannot even express an authorization grant (D7 / ADR PLATFORM-007; kernel contract phase-42). Verdict records carry `recommendsOnly: z.literal(true)`; an `escalate` verdict must name its `escalationRouteRef`; verdicts require ≥ 1 evidence item. `recommendedDefenseAction()` fails closed: hostile → `deny`, suspect → `redact` (AGENTS §19 minimize), indeterminate → `escalate`, benign → defense abstains (abstention is explicitly NOT an allow).
- **Escalation paths per §16 routing.** `defenseEscalationPolicySchema` (`minEscalationSeverity` floor is `notice` — `info` unrepresentable; `requiresHumanClosure` and `recommendsOnly` are schema literals); `defenseEscalationRecordSchema` carries `authorizes: z.literal(false)` — an escalation can never be consumed as an authorization decision; closure is human-only (`closed_by_human` requires a `closedByHuman` record; machine closure does not exist). `decideEscalationPath()` escalates at/above threshold AND unconditionally at `critical` — a policy may lower the threshold, never exempt the most severe class.
- **Fail-closed parsing.** `parseDefenseSurface()` parses an untrusted batch (classifications + verdicts + escalations) with batch ceilings and cross-record invariants: duplicate ids rejected; verdicts referencing unknown classifications rejected; escalations referencing unknown verdicts or classifications rejected — a failed parse never yields a partial surface. `summarizeDefenseSurface()` treats any non-benign classification without a verdict and any not-human-closed escalation as DEFECTS (`ok: false` with structured detail); indeterminate counts as a defect, never a pass.
- **Bounded inputs throughout** — hard ceilings exported (`STATEMENT_MAX_LENGTH`, `SIGNAL_DETAIL_MAX_LENGTH`, `MAX_SIGNALS_PER_CLASSIFICATION`, `MAX_EVIDENCE_PER_VERDICT`, `MAX_*_PER_BATCH`).
- **Composition**: platform primitives read-only (kernel contract phase-42 boundary restated as cited constants); **zero sibling H3 module imports**. Phase boundaries preserved: no authorization decisions (08), no trust evidence (09), no enforcement-path authority, no incident/event ownership (08).
