Static markers pin deep-freeze/strict-object/readonly surfaces per module.

Cross-module transport hygiene: no covered module contains `fetch(` at all, except egress-allowlist where exactly one guarded `globalThis.fetch` handoff exists and a deny decision provably never invokes the transport.
