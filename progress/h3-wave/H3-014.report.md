## Known Risks / FINDINGS (documented behavior tested; engines NOT modified)

- **F-1** `eventDraft` (kernel/reality.ts) emits NO causation coordinates
  (`causation_id`/`parent_event_id`/`declared_origin`): a verbatim draft fails the
  default `requireCause` dedup posture (`EventWithoutCauseError`). Producers must
  attach the causation root before consumption; documented fail-closed tested.
- **F-2** `eventDraft` also emits no issuance provenance (`sequence`/`issuer`), so
  verbatim drafts are rejected by strict consumption (`consumeEvents`);
  `stampEventWithIssuedTime` is the sanctioned bridge (proven).
- **F-3** For digest-identical duplicate deliveries with NO `id` (both fall back to
  the same digest stand-in id), every order coordinate ties and stable sort keeps
  ARRIVAL order: the surviving representative's non-digest fields (e.g.
  `recorded_at`) are arrival-dependent in that edge. Digest-level uniqueness stays
  permutation-invariant (both facts proven). Mitigation: give duplicates distinct
  ids (id tiebreak restores row-level determinism — proven).
- **F-4** `hasIssuanceProvenance` THROWS (via `eventInstantMs`) instead of returning
  false for an event with provenance fields but no parsable occurred_at/recorded_at;
  under strict `orderEvents` that shape surfaces the generic "cannot be ordered"
  error rather than `UnauthoritativeTimeError`.
- **F-5** `consumeEvents` does not force a tenant scope: a multi-tenant batch is
  consumed as ONE stream unless the caller passes `tenantId`. V1 gap — the DB
  consumption path must scope (RLS) and in-memory callers must pass `tenantId`.
- **F-6** `orderEvents` over a SINGLE element never invokes the sort comparator, so
  an event with no parsable temporal coordinate passes a one-element `orderEvents`
  silently; the rejection fires only when events are actually compared. Batch
  consumption (≥2 events) is unaffected.
- Registry state is process-global (module Maps): correct for the in-process V1
  contract, but consumption taxonomy is per-process until the substrate persists it.
