and `frontend/src/lib/mission/delegation-contract.ts`:

1. **Authority bounds at the claim boundary** (`claimWorkerRuntime`):
   - exhaustive ceiling x claim risk-class matrix (every pair in
     `AGENT_RISK_CLASSIFICATIONS`): accepted iff rank(claim) ≤ rank(ceiling);
     escalation denied with the exact `risk_class_escalation_denied:*_above_*`
     reason — never clamped;
   - resource-scope bound: out-of-bounds scopes denied by name (even mixed
     with in-bounds scopes), in-bounds duplicates deduplicated, empty claim
     accepted with zero effective scopes;
   - capability bound: effective authority is exactly delegated ∩ declared,
     order-preserving and deduplicated; undeclared capabilities denied by
     name; `allowedTools` stays empty (tool grants are a separate surface);
   - untrusted-by-default: a worker with zero capabilities and zero scopes
     resolves with zero authority on every dimension; every attempted
     capability/scope is denied;
   - simultaneous multi-dimensional escalation denied, naming the first
     violated bound.

2. **Delegation-depth proofs** (`delegationChainIsNonEscalating`,
   `evaluateDelegationChainAsOf`, `revokeDelegationChain`):
   - a 25-link chain built through the grant-time gate
     (`createDelegation`, alternating strictly-narrowing and equal-width
     grants): accepted, structurally non-escalating, every link's authority
     ⊆ the root delegator's authority, and the deepest link evaluates
     as-of with the full ancestor path (length 25);
   - per-record depth authorization: a deep link denies an action its own
     grant lacks even though the root held it (`action_not_granted`);
   - adversarial topologies: diamond union-closure (authority granted by
     ANY parent legitimizes the child claim; authority granted by NONE is
     rejected by name), escalating link injected at depth denied by
     delegation id, cycle buried at depth rejected as privilege laundering,
     cross-tenant parent link denied (multi-tenancy law);
   - dead links: an expired mid-depth link invalidates the entire
     downstream path (`denyReason: expired`, broken `delegationId` named)
     while upstream links stay usable; suspended/revoked links deny with
     their named reasons; unknown targets fail closed (`record_not_found`);
   - revocation propagation composes with expiry: revocation passes
     THROUGH an expired mid-link and revokes all deeper descendants,
     attributed on every record, while out-of-mission siblings stay
     untouched (scope-bounded propagation, DEFECT-4).
