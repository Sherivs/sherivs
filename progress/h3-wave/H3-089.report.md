## Known Risks (containment findings — recorded, not fixed; modules are read-only to this team)

- **F-1 (fail-open, security-relevant)** `leases.ts` `assertFencingToken`: a **NaN fencing
  token passes the fence** (`NaN < x` and `NaN > x` are both false, so every token check falls
  through) whenever the principal matches and the lease is live. Fencing is the shared-resource
  writer gate. Recommended fix: reject non-finite tokens (`stale_fencing_token`/`unknown_lease`).
- **F-2** `quotas.ts` `consume`: a lease plane that **throws** (contract violation) escapes the
  admission boundary uncontained (before any ledger mutation — no state corruption). Recommend
  try/catch → typed `lease_not_active` at the adapter boundary.
- **F-3** `leases.ts`: `targetKey()` runs **before** `validateAcquireRequest()`, so a null /
  non-object target crashes `acquire`/`enqueueWaiter`/`cancelWaiter` with a raw TypeError; the
  validator's null-target branch is dead code on those paths.
- **F-4** `chains.ts` `openResolutionFlow`: a non-JSON-serializable `subject` (BigInt → raw
  TypeError; circular → RangeError) escapes instead of `ResolutionFlowError("invalid_input")`.
- **F-5 (fail-open, security-relevant)** `chains.ts` `describeIneligibleRecord`: a forged record
  with an **unparseable `decidedAt`** (NaN time) passes eligibility — the deadline re-derivation
  is fail-open — and the case is **approved**. Recommended fix: non-finite `Date.parse` → defect.
- **F-6** `chains.ts` `resolveFlow`: a forged record without `evidence` crashes with a raw
  TypeError (`record.evidence.trim()` unguarded) instead of a typed `invalid` outcome.

Each finding is asserted in the battery's final describe block as a tripwire of current
behavior with an inline comment; fixing a gap requires flipping that assertion to the typed law.
