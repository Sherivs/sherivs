## Implemented

`frontend/src/lib/evolution-engine/contracts.ts` — a Zod-typed, fail-closed, domain-neutral contract module for the phase-38 substrate surface, composed with platform primitives read-only (imports `PHASE_38_EVOLUTION_ENGINE` from `frontend/src/lib/kernel/phase-contracts/`; no sibling H3 modules imported):

- **No second engine (ADR PLATFORM-004):** every program id must live in the `evolution38.` kernel-contract namespace; `composedCapability` is an enum restricted to exactly the capabilities the phase-38 kernel contract declares as consumed (`evolution-lifecycle`, `governance-alignment`, `universal-reality-ontology`). There is no schema path to register a new capability (strict objects reject it).
- **AGENTS §8 law encoded:** `classifyProposalAutonomy` maps change scope × permission impact to ALLOW / REQUIRE_APPROVAL / ESCALATE. `security_boundary` escalates even when claiming `no_access_change`; `access_widening` escalates in every scope; ALLOW exists only for read-only/derived work that provably grants nothing. `SELF_IMPROVEMENT_LAW` names the §8 rule verbatim for audit.
- **AGENTS §21 gate chain:** `advanceGateChain` enforces proposal → validation → policy_check → approval → execution → audit in canonical order; out-of-order runs and blocked gates terminate the chain fail-closed; execution is unreachable without a prior approval gate.
- **Independence:** `ratifyProposal` refuses self-ratification (proposer ≠ approver) and admits only external governance authorities — no proposing authority exists in the approval vocabulary, so a proposal cannot ratify itself in type.
- **Staged & reversible:** every stage requires a rollback plan and ≥1 declared invariant; stages must be sequential from 0 without gaps/repeats; bounded (64 stages/program, 256 programs/registry, 32 invariants/stage).
- **Fail-closed invariant verification:** `evaluateStageCompletion` completes a stage only when every declared invariant is verified `held` for that stage index; missing/not-run/violated/unknown evidence each keep the stage open; orphan verifications for undeclared stages fail program completion (`evaluateProgramCompletion`).
- **Provenance mandatory (AGENTS §12);** canonical-truth separation documented (impact estimates are derived intelligence, never authority).

## Security Validation

- Fail-closed everywhere: schema violations and cross-record invariants return typed `{ ok: false, issues }`; no partial program/registry is ever produced.
- `z.strictObject` throughout — unknown keys (e.g. a hypothetical `selfRatifiable`/`ownsCapability`) are rejected, so permissive semantics cannot leak in.
- §8 encoded structurally: no scope, authority, or input makes access-widening or boundary-touching work autonomous; approval authority vocabulary contains no self/proposing authority.
- Provenance required on every declaration; no secret-shaped fields, no logging, no I/O, no vendor imports.
- Domain neutrality (J-037): zero education/domain tokens in either owned file (verified by scan).
