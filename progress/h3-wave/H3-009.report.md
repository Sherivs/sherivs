## Implemented

Extended `frontend/src/lib/security/credential-broker.ts` (additive only; every pre-existing export, reason string and test contract preserved) with per-agent scoping enforcement depth:

1. **Per-agent scoping policy (`AgentScopingPolicy`) + registration.** New injectable per-identity policy: `maxActiveLeasesPerCredential`, `maxTotalActiveLeases`, `maxLeaseTtlMs`. Registered via `registerAgentScopingPolicy` with fail-closed **Zod** validation (rejects non-positive caps, invalid identity refs, non-finite/non-positive TTL bounds); an invalid policy is never partially registered. Re-registration replaces (latest wins). `agentScopingPolicy()` read accessor; `null` = unconstrained at this layer (the authority intersection still binds everyone).
2. **No universal master credential — shape-level depth.** `registerCredentialPolicy` now also rejects master-credential *shapes*: a wildcard (`"*"`) resource scope and a wildcard capability requirement, each with an explicit no-master-invariant error string. (The existing type-level and runtime empty-capability rejection is untouched.) Rejected policies are never registered — nothing leases against them.
3. **Least-scope issuance.** `evaluateAgentScoping` (exported pure function) enforces: per-credential concurrency cap → deny; total concurrency cap → deny; per-agent TTL bound → **clamps issuance DOWN** to the narrowest bound, never widens. `grant` integrates the verdict: denial reasons `agent_scope_concurrency_denied:<n>_per_credential` / `agent_scope_total_leases_denied:<n>`, and the lease `expiresAtMs` uses the clamped TTL. Caps are a conjunction (a tight total cap with a loose per-credential cap is valid and enforced).
4. **Expiry honored (in budget accounting and at use).** Active-lease counting excludes expired and revoked leases (they release concurrency budget) and includes exhausted-but-unexpired leases (conservative, fail closed). Added `activeLeaseCount(identityRef, credentialRef | null, nowMs)` with coherent time semantics: a lease not yet issued at `nowMs`, or lapsed at `nowMs`, does not count. Denials, clamped grants and use-time expiry (`lease_expired`) all audited.

All new code is strict TypeScript, Zod-validated at the registration boundary, no `any`/`z.any`, no new dependencies (`zod` already a repo dependency), no domain vocabulary, no secret material in any new surface.

## Security Validation

- **No universal master credential:** deeper than type-level rejection — wildcard scope/capability shapes are a registration contract error; the failed registration leaves `credential_not_brokered` semantics for any grant attempt (tested).
- **Least scope:** grants can only be narrowed, never widened, by construction (`evaluateAgentScoping` clamps down only); proven at handle and view level.
- **Expiry honored:** lazy expiry denies at use (unchanged), and expiry/revocation deterministically release concurrency budget; not-yet-issued leases do not count (time-coherent accounting with caller-supplied clocks).
- **Fail closed:** invalid scoping policies are rejected whole; vault-entry, lockdown, tenant, capability, risk and scope checks all run BEFORE the scoping layer, so the extension adds restrictions only.
- **Non-observability:** no secret material in any new type, event, view or reason string; guard test asserts clamped-lease handles serialize secret-free; audit remains secret-free.
- No git commands run; no database/network access; no secret values printed, logged, or written (test fixtures use synthetic literals only in vault provisioners, as the pre-existing tests do).

## Known Risks

- Per-agent scoping is enforced only at this broker boundary; a deployment that never registers `AgentScopingPolicy` gets no per-agent concurrency limits (authority intersection still applies). Wiring policies from workforce definitions is future work for the workforce layer.
- Active-lease counting is O(all leases) per grant in the in-memory V1; acceptable at V1 scale, worth an index if lease volume grows.
- `activeLeaseCount`/grant accounting treat a not-yet-issued lease as nonexistent at earlier clock times — correct for caller-supplied time, but callers that move clocks backwards will see leases "not yet existing" again.
