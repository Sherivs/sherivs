## Implemented

Authored the Zod-typed, fail-closed, domain-neutral CONTRACT module for the phase-41 substrate surface (`sandbox-runtime`), read-only composed with platform primitives (Zod only; no sibling H3 imports, no vendor imports, no I/O):

- **Sandbox provisioning** (`SandboxProvisioningSchema`): tenant-scoped, purpose-mandatory (§16), provenance-mandatory (§12), resource-bounded (unbounded sandboxes do not parse), temporality enforced at the schema level (`expiresAtMs > createdAtMs` refine — sandboxes are temporary by mandate). Fail-closed literals: `isolation: "isolated"`, `credentialScope: "non-production"`, `canonicalWriteback: false` — no other values parse.
- **Canonical mirror grants** (`MirrorGrantSchema`): grant-scoped, policy-scoped, purpose-scoped, expiring mirroring of canonical subjects into a sandbox; redaction is mandatory (`z.enum(["minimized","redacted"])` admits no unredacted value — §19 data minimization).
- **Agent grants** (`AgentGrantSchema` + `evaluateAgentGrant`): least-scope, expiring, revocable grants for agents to act inside one sandbox; fail-closed ordering (invalid input → tenant → sandbox → lifecycle → sandbox expiry → grant-outlives-sandbox → grant expiry → revocation → credential scope). Credential-scope escalation is DENIED, never silently narrowed.
- **Execution runs** (`SandboxRunRequestSchema`): seeded (reproducibility mandatory), step-bounded, purpose-mandatory, `executionIsolation: "isolated"` literal.
- **Run bundles + validation** (`SandboxRunBundleSchema` + `validateSandboxRunBundle`): shape (Zod) → cross-field invariants (tenant mismatch, sandbox/run mismatch, non-active lifecycle, observations only for completed runs and mandatory for them, duplicates, inverted/expired validity, unknown mirrored subjects, uncontained escape events, resource/step bound exceedances) → freshness against the caller-injected clock. All issues collected, never truncated.
- **Derived-only outcomes** (`SandboxObservationSchema`): `origin: z.literal("derived")` — the §9 label is unforgeable; confidence-scored, expiring, audit-referenced.
- **Run admission** (`admitRun`): fail-closed usability decision for admitting another run into a sandbox right now (not_active / sandbox_expired / tenant_mismatch).
- **The ONLY bridge toward canonical surfaces** (`SandboxPromotionProposalSchema` + `PromotionApprovalSchema` + `decideSandboxPromotion`): proposal-only promotion implementing AGENTS §16/§21 (Proposal → Validation → Policy → Approval → Audit). Fail-closed ordering: invalid input → no policy → no audit destination → evidence must exist and be internally consistent → source sandbox must be TERMINATED (cleanup precedes promotion) → zero escape events (any escape, contained or not, is a breached boundary) → approval absent = REQUIRE_APPROVAL; mismatched/expired/revoked approval = DENY. The module can DECIDE, never execute — no write surface exists.
