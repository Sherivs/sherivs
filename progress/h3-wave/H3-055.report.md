## Implemented

A Zod-typed, fail-closed, domain-neutral CONTRACT module for the phase-35 substrate surface, derived from what phase 35 IS declared to own (kernel contract `frontend/src/lib/kernel/phase-contracts/phase-35-agent-civilization.ts`; capability `multi-agent-society-governance`; acceptance map `architecture/phase-acceptance/phase-35-autonomous-agent-civilization-os.json`):

- `society:form` — `parseSocietyDefinition` with cross-record invariants: ≥2 members (a one-member "society" duplicates the agent runtime, phase-07 territory, D6), duplicate member seats denied, bounded membership (1024), strict shapes (no smuggled fields), provenance required.
- Society lifecycle — approval-gated transitions (`transitionSociety`): activation/re-activation/dissolution require an explicit approval record; rejected is a free deny path; dissolved is terminal; only `active` operates (`isSocietyOperational`).
- Intersection-of-grants authority — `societyAuthorityIntersection` / `evaluateCollectiveAction`: collective authority is exactly the intersection of all members' declared grant views; a member whose identity is unusable contributes an EMPTY grant set via `effectiveMemberGrants`, so authority can shrink but never widen; denies enumerate exactly which members lack the action.
- `society:coordinate` — `evaluateCoordination`: both endpoints must be current members with usable identities (`isIdentityUsable` from `../identity`, composed read-only); unknown sender/recipient, non-participating identity, non-active society and society mismatch all deny.
- Collective decision rules — `resolveCollectiveDecision`: attributable one-vote-per-participant ballots; quorum floor cannot be declared below half the participation; silence resolves to no_agreement (never agreement); unanimity breaks on any rejection/abstention/missing vote; majority ties resolve to no_agreement; observers do not vote; an `agreed` verdict never widens authority (separate gate from the intersection).
- Collective output trust — `registerCollectiveOutput` (born `unvalidated`) + `validateCollectiveOutput`: only an approved verdict from a participating member flips output to trusted (AGENTS §21; kernel AI-safety section).
- Suspension — `applySocietySuspension`: society-scope suspends the unit (member records untouched — no collateral); member-scope names exactly one member; unknown member, missing memberRef, scope mismatch and non-active society deny.
- `society:audit` — `parseSocietyAuditTrail`: append-only immutable trail, every entry attributed to ≥1 named actor (no anonymous collective action), duplicate entry ids deny the whole trail, bounded at 65536 entries, six kinds covering every society surface.

## Security Validation

- Fail-closed by construction: every adversarial input in the suite yields a typed deny with a named code and structured detail; no partial societies, trails or authorities are ever produced by a failed parse.
- Agents untrusted by default (AGENTS §5): an empty grant view holds zero authority; unknown members/voters/validators are denied, not absorbed; coordination outside declared membership is impossible.
- No aggregation into authority: the intersection rule is the only authority surface, and identity suspension collapses it — the suite proves authority can only shrink.
- No anonymous collective action: attribution (≥1 named actor) is schema-mandatory on every audit entry; coordination attributes both endpoints; votes name their voter.
- Untrusted collective output (AGENTS §21): born unvalidated; only a participating member's approved verdict flips trust; rejected verdicts leave output unusable forever.
- No secret handling, no logging, no network egress surface; ids/refs are bounded and control-character free.

## Known Risks

- Member grant views are caller-supplied DECLARED VIEWS; the authoritative grant records live in phase 07/08 substrate. A caller passing a stale or inflated view would gain authority it does not hold — the module documents this and never mutates or re-derives grants; binding to the live grant source is future integration work (verifier G-073 can probe this seam).
- Decision quorum floor is participation-relative; a society that shrinks (suspended members) lowers its own floor — intentionally fail-closed because suspended members also collapse the intersection, so agreement can never out-run authority.
- The kernel `society:coordinate` API surface is represented as pure evaluation functions; persistence/transport wiring (route queue, realtime) is out of scope for a contract module and remains architecture-declared (acceptance area `live-society-coordination-and-audit`).
