## FINDINGS (attacks that succeeded — module NOT patched, per law)

- **F1 — No agreement-binding on the surface (medium).**
  (a) `parseFederationAgreement` accepts two agreements sharing one `agreementId`
  with divergent `sharedFieldPaths` (replay of the identifier is undetectable on a
  stateless surface). (b) `parseSharedStateEnvelope` accepts an envelope whose
  tenant pair (`tenant_x` → `tenant_y`) is unrelated to the parties of the
  agreement it attributes itself to (`fed:agreement-1` between `tenant_a`/`tenant_b`).
  (c) `parseTwinRelationship` accepts a same-tenant relationship attributed to a
  cross-tenant agreement. Each parse is individually well-formed, but the surface
  provides no typed composition helper (e.g. `validateEnvelopeUnderAgreement`) and
  no cross-artifact binding — attribution is asserted, never enforced. Tenant/scope
  binding is entirely a caller duty, which an adversary can exploit by feeding
  mis-bound artifacts to a compliant caller. Containment that DOES hold: the gate
  never consumes envelope tenants and honors only its own artifact's allowlist, so
  no smuggled artifact widens an agreement's scope.
  *Recommendation (for G-066/wave command, not implemented):* add a typed
  agreement-aware validation helper binding envelope tenants + agreementId +
  fieldPath to the parsed agreement's parties and allowlist.
- **F2 — Unbounded free-text fields bypass digest-only minimization (low/medium).**
  `federationProvenance.policyRef` and `confidence.method` are `nonEmptyString`
  with no maximum length. An untrusted sender can inline an arbitrary payload
  (verified: a JSON blob containing `secretField` round-trips through
  `parseSharedStateEnvelope` and `parseTwinRelationship` inside these fields),
  defeating the "payload travels by digest, never by value" law at the artifact
  level. Identifier-bounded fields (actorId, traceId, tenantId) refuse the same
  payload. *Recommendation:* bound these fields (max length + pattern) like
  `identifierSchema`.

## Known Risks

- **KR-1 (from F1):** cross-artifact binding (envelope↔agreement,
  relationship↔agreement, agreementId uniqueness) is caller-duty; the surface
  gives no typed helper, so a compliant-looking caller can be fed mis-bound artifacts.
- **KR-2:** `classification` and `redacted` are sender-declared; a restricted
  payload mislabeled `internal` parses (the surface cannot verify true
  classification). Downstream consumers must not treat parsed classification as
  ground truth.
- **KR-3:** zod v4 `strictObject` silently strips a `__proto__` own key instead of
  refusing it with `invalid_shape` — the strict-surface refusal law is evaded for
  that key name specifically. Harmless in effect (parsed output is clean, no
  pollution), but an artifact that should fail parsing succeeds.
- **KR-4:** the gate's expiry check compares ISO strings lexicographically
  (`now >= expiresAt`). All schema-accepted datetimes are `Z`-suffixed and
  fixed-width, so this is chronological except for mixed precision: an exchange
  at the exact expiry instant is allowed when `now` is expressed without
  milliseconds and `expiresAt` with them (e.g. `…T10:00:00Z` vs `…T10:00:00.000Z`).
  Boundary-narrow; canonical-format equality is correctly denied.
