   the shared identity-actor primitives; worker administration is designed
   service-role-only (migration posture note). A client-facing policy is

   contradiction. Enforcement first, visibility later (§21 ordering).
   PROPOSED (condition-gated): worker-SELF tenant-scoped read via a neutral
   self-derivation pin, only after (a) an authorized client surface and
   (b) FINDING-1 closure; delegation-history reads stay service-role.

3. **`cg_worker_capability` — ZERO-POLICY-BY-DESIGN.** Same migration

   `workforce/capability-registry.ts` (J-028 capability-over-agent-count).
   Traced: zero `.from("cg_worker_capability")` usages. A capability row IS

   no silent permission expansion). PROPOSED (dependent clause of the
   definition proposal): worker-SELF read visibility only; write commands
   stay absent forever, encodable as `absentPolicies` in a future posture
   entry.
