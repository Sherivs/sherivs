## Implemented

Authored the phase-44 substrate-surface contract module — Zod-typed, fail-closed, domain-neutral, pure (no I/O, no vendor imports, no wall-clock reads, no secrets):

1. **Distributed-node identity** (`distributedNodeIdentitySchema`): provenanced, owned, purpose-declared nodes (AGENTS §43) with lifecycle states (AGENTS §6), declared capability sets, and key FINGERPRINTS only — raw key material is structurally rejected (`sha256:`-prefixed hex digest pattern). Forward-only lifecycle transition table (`decideNodeLifecycleTransition`): no silent standing increase; entering `deployed` and leaving `suspended` require a VALID human approval record parsed fail-closed (machine-authored approvals rejected, AGENTS §8).
2. **Region topology** (`regionTopologySchema` + `parseRegionTopology`): bounded region registry with jurisdiction/residency declarations and capacity units, typed links; fail-closed parsing — duplicate region ids, duplicate ordered-pair links, unresolved link endpoints, and self-links yield structured issues, never a partial topology.
3. **Residency beats availability**: only `control`/`storage` region kinds are structurally tenant-data-eligible (`TENANT_DATA_ELIGIBLE_REGION_KINDS` + schema refine); `compute`/`edge`/`worker` regions can never claim eligibility (mirrors the phase-44 acceptance invariants).
4. **Fail-closed region admission (E-060)**: `decideRegionAdmission` gates in order — `unknown_region`, `region_not_tenant_data_eligible`, `node_not_operational`, `explicit_trust_decision_required` / `trust_decision_invalid`, `trust_decision_node_mismatch`, `distrusted_by_decision`. The automatic verdict space is only `unproven | untrusted` (`effectiveTrustVerdict`); `trusted` is reachable exclusively through an explicit provenanced decision (`decidedBy`, `authority`, `reason`, `basisEvidenceRef`, `decidedAt`). `admissionPolicySchema.requireExplicitTrust` is `z.literal(true)` — the surface cannot even express an auto-trust policy. Admission carries `basis: "explicit_trust_decision"` as its audit basis. Request parsing (`parseAdmissionRequest`) refuses capability expansion: requests may narrow, never widen, a node's declared capabilities.
5. Exported boundary constants (`DISTRIBUTED_INFRASTRUCTURE_BOUNDARY`, `EXTERNAL_NODE_TRUST_POSTURE`) so downstream surfaces cite rather than paraphrase.

## Security Validation

- **E-060 enforced and tested**: an admission with every other gate passing still denies without an explicit decision (`explicit_trust_decision_required`); malformed decisions deny (`trust_decision_invalid`) rather than widen; a `trusted` verdict for a different node denies (`trust_decision_node_mismatch`); the policy schema's `z.literal(true)` makes auto-trust inexpressible.
- **Fail-closed parsing everywhere**: topology, admission requests, trust decisions, and human approvals are all parsed from untrusted input; failures return typed reasons with structured issues and never partial results.
- **Residency**: tenant-data placement on compute/edge/worker regions is denied twice over — schema-level (region cannot declare eligibility) and decision-level (placement intent denies).
- **Provenance (AGENTS §12)**: nodes, regions, policies, and trust decisions all carry `declaredBy`/`authority`/`declaredAt`; decisions additionally require reason + evidence basis.
- **Secrets**: the only credential-shaped surface is the key-fingerprint schema, which accepts `sha256:` hex digests and structurally rejects raw key material; no secret values are printed, logged, or written anywhere.
- **J-037 neutrality**: static scan of the module for domain vocabulary (school, student, farm, crop, hospital, weather, climate, satellite, etc.) — zero matches.

## Known Risks

- The admission model is contract-only: policy evaluation against runtime state (e.g., pending-admission counts against `maxPendingAdmissions`) is not computable in a pure module and is left to the owning enforcement layer; the ceiling is declared, not polled.
- `linkKind` and `weight` are intentionally coarse (class-level, not measured latency); a future phase may refine them without breaking the contract's shape.
