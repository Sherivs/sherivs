Mission A-001 (Squad A — Recovery & Resilience, M-R-101 groundwork). Role: Recovery Drill Runner Engineer. Date: 2026-10-03.

## Implemented

`scripts/verify-recovery-drill.mjs` — a self-contained recovery-drill verification runner in the battery exemplar's image (`scripts/apply-canonical-hardening.mjs`): declared contracts, fail-closed exit semantics (0 PASS / 1 FINDING / 2 BLOCKED_NO_CREDENTIAL or BLOCKED_USAGE), guarded artifact writes (`COREGRID_ARTIFACTS_DIR`, default `/opt/cursor/artifacts`), and a transcript log. Sibling squad-A modules are deliberately NOT imported — all contracts are embedded:

- **Drill plan** (7 declared steps, single source of truth): prepare → backup → destroy → restore → verify-identity → verify-evidence → cleanup, with invariants: unique ids; every `destroy` declares a restore counterpart and a verify step that must follow it; backup precedes any destroy; prepare precedes backup; `cleanup` is the terminal step.
- **Backup-manifest contract** (embedded Zod 4, `z.strictObject` fail-closed on unknown keys): `kind` literal `coregrid-recovery-backup-v1`, scope (coverage mode, record families, tenant ids), `takenAt`/`expiresAt` UTC instants, sha256 checksums (per-row digests + manifest digest, hex64), tenant coverage. Invariants: expiry must be after the taken instant (expired sets fail closed), tenant coverage must exactly equal scoped tenants, row ids unique. Exercised offline against a known-good vector plus six known-bad vectors (unknown key, bad kind, missing expiry, non-UTC instant, bad digest, empty tenant scope).
- **Recovery-target contracts** (RTO/RPO per record family, fail-closed): four scoped families (`canonical-primitives`, `evidence-ledger`, `runtime-configuration`, `worker-substrate`) each require exactly one declared target with positive RTO, non-negative RPO, RPO ≤ RTO, and a named owner role — no implicit defaults; a scoped family without a target is a FINDING.
- **`--rehearse` mode** (offline, zero network, zero database, zero credential): runs plan invariant validation, target-contract validation, manifest shape vectors, and scans the manifest store (`COREGRID_RECOVERY_MANIFESTS_DIR`, default `architecture/proofs/recovery/manifests`) validating any manifests found (store absence is not a finding; present-but-invalid manifests are). Writes `recovery-drill-rehearsal.json`/`.log` artifacts with `databaseContact=false`, `networkContact=false`.
- **Live mode (default)** — strictly credential-gated: without `SUPABASE_ACCESS_TOKEN` it fails closed with `BLOCKED_NO_CREDENTIAL` before doing anything (exit 2, verified: nothing probed, no artifact written). With the credential it re-runs the full offline rehearsal (any finding aborts before contact) and then performs exactly one read-only reachability probe (`SELECT 1`) on the authorized Management API query channel. Never destructive; the destructive restore drill remains owned by `scripts/restore-recovery-drill.mjs` and the A-004/A-005 runbooks. Credential values are never printed, logged, or written.
- Discipline: JSDoc-typed helpers, Zod-validated shapes, no `any`, no `z.any()`, no eval, no dynamic code, no secrets, neutral vocabulary only.
