## Implemented

`frontend/src/lib/reliability/quotas.ts` — resource-quota contracts layered on the EXISTING lease contracts (`frontend/src/lib/reliability/leases.ts`, read-only import; never modified):

1. **Zod-validated quota registry (fail-closed parse).** `quotaCeilingSchema` — one binding per (scope `tenant|agent`, principalRef, resourceClass): `maxUnitsPerWindow` (non-negative whole, hard ceiling `MAX_UNITS_PER_WINDOW = 1e9`), `windowMs` (bounded by `MAX_QUOTA_WINDOW_MS = 24h`, fixed windows anchored at the epoch), and MANDATORY provenance (`declaredBy`, `authority`, ISO-8601 `declaredAt` — AGENTS §12). `parseResourceQuotaRegistry(unknown)` returns a typed result with structured issues; duplicate bindings are a parse failure (one binding per scope+principal+class, never a silent override); zero-limit ceilings are valid deny-all bindings.
2. **Fail-closed admission (`ResourceQuotaAuthority.consume`).** Denial order: `invalid_input` → lease layer → `undeclared_quota` (tenant, then agent — an undeclared principal admits NOWHERE) → `quota_exhausted` (first breaching scope denies, tenant then agent). Exhaustion carries a structured `QuotaExhaustionDetail` (scope, principal, class, limit, consumed, window bounds, `retryAtMs`). Per-consumption unit ceiling `MAX_UNITS_PER_CONSUMPTION = 1e6`.
3. **Lease layering (the volume plane over the concurrency plane).** A consumption MAY present a lease binding (`LeaseHandleRef` from `./leases`). When presented, the authority consults an injected `QuotaLeasePlane` (structural interface satisfied by `LeaseQuotaGovernor.assertFencingToken`) and fails closed: a stale/expired/foreign handle denies `lease_not_active`; a lease binding with NO lease plane configured denies `lease_plane_unavailable` — never a bypass. The consuming principal must equal the binding's holder principal.
4. **Atomic multi-scope charging.** A consumption by an agent charges BOTH its tenant and agent ledgers; admission is two-pass — every in-scope ceiling must clear BEFORE any ledger is mutated, so a denied consumption leaves no partial charge (bug caught by this mission's own suite and fixed).
5. **Window semantics.** Fixed epoch-anchored windows evaluated lazily from the injected clock (AdapterClock pattern; nothing runs implicitly, no timers); rollover restores capacity exactly and only then; `pruneClosedWindows()` drops unreclaimable windows.
6. **Observability.** Append-only in-memory audit trail (`quota_consumed` / `quota_denied`), injectable event sink whose failures are contained (observability never breaks containment); `snapshot()` gives a fail-closed per-scope view (undeclared ⇒ `declared: false`, limit 0, `remainingInWindow: null`); `totals()`.

Neutral vocabulary only (J-037 shrink-only): resource class / units / windows / principal. Pure in-process contract: no I/O, no persistence, no vendors, no secrets.

## Security Validation

- **Fail closed:** undeclared principals/classes admit nowhere; zero limits deny everything; expired/stale/foreign lease bindings deny; missing lease plane denies; invalid input denies before touching state. No permissive default exists in any path.
- **Denials are audited, never silent:** every admission and denial is an append-only event; the typed deny is a structured decision, not a slowdown.
- **No canonical access:** no database, no network, no credential surface; no secret values printed, logged, or written; nothing applied.
- **Layering, not weakening:** quotas add restrictions ON TOP of the lease plane; `leases.ts` untouched; no existing test modified or weakened.
- **Tenant boundary:** tenant equality is enforced between consumer and lease binding before any fence consultation; agent consumption is charged to its tenant's ledger, so agent volume can never outrun tenant ceilings.
