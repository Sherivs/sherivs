## Implemented

- `scripts/verify-provenance-metadata.mjs` — offline machine check that key governance artifacts carry provenance metadata per AGENTS §12. Contract dimensions and their checked-in-convention matchers:
  - **origin** (where did this come from) — authority citations (`Authority:`, `Cites`, `Supersedes`, `Contract:`), derivation citations (source/creating migration, created/corrected by, machine source of truth, `Provenance of`), mission-graph citations (`Mission: <id>`), campaign-law citations, or cited in-repo artifact paths.
  - **creator** (who created it) — an agent identity under AGENTS §5: wave team id (`H3-NNN`), mission id (`X-NNN`, `MISSION-R-NNN`, `H2-NN`, `mrNNN`). Per wave convention every artifact is authored by a numbered agent team, so the team attribution doubles as the AI-generated disclosure.
  - **createdAt** (when) — inline ISO date required for authority artifacts (ADRs, campaign record); wave-scope classes resolve dating via **wave-inheritance** from the dated campaign record (the wave provenance root), with every inheritance-reliant artifact disclosed as an advisory, never silently OK.
  - **verification** (verified? / trustworthy?) — declared decision posture: `Status`/`Verdict`/`Decision`/`Disposition`/`Adjudication` markers, `STATUS=` battery lines, Governed-(not)-executed / nothing-applied honesty markers, `Tests:`/`## Tests`/`## Evidence` report sections, or explicit no-execution claims (`zero test execution`).
  - **identity** — `AGENTS.md` (the root authority; it defines provenance, so it self-identifies via Document/System/Version instead of citing a higher source).
  - **declared-fields** — `architecture/adr/TEMPLATE.md` (a template's provenance is its declared Status/Date/Author/Mission field schema).
- Artifact classes (first match wins): `root-authority` (AGENTS.md), `adr-template`, `campaign-record` (`H3-WAVE-CAMPAIGN.md`), `adr` (`architecture/adr/**`), `runbook` (`docs/runbooks/**`), `wave-doc` (`architecture/campaigns/h3/**`, `architecture/observability/**`), `wave-report` (`progress/h3-wave/**`). ## Known Risks

- **Matcher-based contract.** Provenance recognition is lexical (regex matchers over checked-in conventions). A rewrite of an artifact's header conventions could evade a dimension; the contract is declared as data (`PROVENANCE_CONTRACT`) and adjusters must extend matchers, not delete dimensions, without an ADR.
- **Concurrent wave drift.** Squad J siblings are landing files while this battery exists; a sibling artifact that omits required provenance will flip the battery to exit 1 — that is the checker working, but it can transiently redden this suite.
- **Typecheck of `.mjs` import surface.** The test deliberately avoids importing the `.mjs` module (spawnSync-only, like the H3-001 exemplar), so no `allowJs` declaration is needed; residual strict-TS risk is nil for this pair.
- **Wave-inherited dating.** 67 wave-scope artifacts carry no inline date; their dating is inherited from the campaign record. A future wave should add inline dates (outside this mission's ownership).
