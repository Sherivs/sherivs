## Implemented

Root-caused the flake with a ground-truth reproducer before changing anything:

1. **ROOT CAUSE (empirical, not assumed).** `spawnSync` with piped stdio intermittently
   **truncates large child output while still reporting `status=0` / `error=undefined`**.
   Repro under artificial CPU contention (10 CPU burners): 6/15 iterations captured only
   127–159 KB of the guard's 212,914-byte report, tail cut mid-line, clean exit 0.
   The guard's final `STATUS=PASS` footer silently vanished — exactly the historical flake
   signature of this suite's standing-oracle test. This is a pipe-drain race in the sync
   spawn path, load-dependent, invisible in sequential runs.
2. **Fix — file capture instead of pipes.** The child now writes stdout/stderr to files
   inside the isolated scratch directory (`stdio: ["ignore", <fd>, <fd>]`); the parent
   reads them back after exit. Repro re-run under identical contention: **0/15 anomalies**
   (was 6/15). Pipe truncation class eliminated at the mechanism level.
3. **Isolated child environment.** Unique per-attempt temp dir via `mkdtempSync` (no
   shared-/tmp collision); `TMPDIR` redirected into it; parent-injected `NODE_V8_COVERAGE`
   redirected into the same isolated dir (no shared coverage-folder contention); stdin
   detached (`ignore`); `windowsHide` set.
4. **Generous-but-bounded timeouts.** 60s child timeout with `SIGKILL`; per-test vitest
   budget of 240s (the file's spawn previously ran under the repo-wide 30s default with
   no child bound — an orphan-risk under contention).
5. **Documented bounded retry (same expectations, evidence-only).** At most 2 extra
   attempts, ONLY when the spawn produced no verdict (`result.error` set, no exit code:
   EAGAIN fork exhaustion, ETIMEDOUT). A completed run's exit code is evidence: non-zero
   exit or any assertion mismatch fails immediately and is never retried — the retry
   cannot mask a real neutrality failure.
6. **Oracle untouched — strengthened, never weakened.** All original expectations are
   verbatim (certified-file FAIL-line filter → `[]`, no `/RATCHET/`, `/STATUS=PASS/`,
   baseline capability-gate ratchet assertions). Two assertions were ADDED: the spawn must
   have `error === undefined` and `status === 0` before the oracle runs (a killed/timed-out
   child is no longer silently treated as a pass).
