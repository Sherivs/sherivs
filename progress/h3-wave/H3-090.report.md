- Read-only: writes nothing; touches only its own ownership files (authored separately).
- No secrets read, printed, or written; the script accesses no environment credentials. Secret values appear nowhere in the doc or script.
- Reports the credentials-gated integration test's offline-skip semantics so the offline guarantee of the verify chain is explicit and auditable.

## Known Risks

- Test-call-site counts are regex upper-bound estimates (comments/strings containing `it(`/`test(` inflate them); they are labeled "est." in output and are not collected vitest counts.
- Runtime budgets are policy classes, not measured timings; the doc states this explicitly. Actual chain wall clock may differ by machine.
- Steps added to the verify chain later fall back to command-shape classification and print "(not yet in the census map)" until the doc is updated — fail-open in a doc generator (never a CI gate), by design.
- The census doc's counts reflect the wave-in-progress tree (H3 test files included); the coordinator should regenerate after the wave lands.
