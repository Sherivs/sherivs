# V1-007 — CoreGrid Platform Public Site (team WEB) — §42 Report

Mission: V1-007, CoreGrid V1 program. Version-target classification: **V1** (platform
presentation surface; no device/IoT (V2) and no Reality-Intelligence capability
(V3) scope is implemented, touched, or claimed).

## Implemented

The CoreGrid platform public marketing site — the page that did not exist for any
visitor: what CoreGrid is, its capabilities, its security posture, its pricing, and
a real visitor→signup path.

1. **Route-tree choice (stated, per mission).** New pathless layout group
   `frontend/src/routes/(site)/`, mirroring the existing `_authenticated` pathless
   group convention. The platform site is exposed at **`/coregrid`** — verified
   non-colliding against the full existing route tree (155 modules). Content
   modules live in `frontend/src/routes/(site)/-content/` (the router generator's
   default `-` ignore prefix keeps them out of the route tree), keeping file
   ownership entirely inside the new group.

2. **Routes**
   - `frontend/src/routes/(site)/route.tsx` — id `/(site)`; shared marketing shell:
     sticky header (brand, section anchors, "Kernel detail" → `/platform`,
     Sign in / Sign up → `/auth`), `<main id="main-content">`, footer with
     platform/account navigation.
   - `frontend/src/routes/(site)/coregrid.tsx` — id `/(site)/coregrid`; the landing
     page with sections: hero (what CoreGrid is: AI-native institutional operating
     system / Universal Reality Intelligence Platform), platform capabilities
     (reality model, missions, AI workforce, evidence, governance, workspace),
     domain runtimes, security & governance, pricing, final CTA band.

3. **Typed content modules (no scattered JSX data)**
   - `frontend/src/routes/(site)/-content/pricing-tiers.ts` — `MarketingTier`
     interface + `MARKETING_TIERS` + `formatTierPrice()`. Tier data mirrors the
     platform's commercial tier catalog (`frontend/src/lib/subscription-tiers.ts`,
     ₦ prices) in copy form. That module is frozen for new consumers
     (MISSION-R-73 header), so this is a typed presentation view, deliberately
     NOT an access-decision surface and NOT a new consumer of the frozen module.
   - `frontend/src/routes/(site)/-content/site-content.ts` — `SITE_CAPABILITIES`,
     `SECURITY_GUARANTEES`, `INSTALLED_RUNTIME_PROOFS` view-models.

4. **Domain runtimes section (runtime extension, never platform identity).**
   Scholar is presented exactly as the runtime layer names it
   (`runtime:scholar`, "African Education Runtime", runtime-001) as *proof of
   kernel neutrality*: the school inherits the governed core and brings only its
   own domain; remove it and the kernel stays valid. No copy frames Scholar as
   the platform; verified below against platform-neutrality LAW 3 / LAW 5.

5. **Auth CTAs link the REAL auth surface.** All sign-up / sign-in CTAs link to
   `to="/auth"` (the platform's single auth page, where account creation is the
   "Create account" mode; `/login` redirects to `/auth`). 13 real `/auth` links
   render on the page. No contact/signup form exists — zero `<form>` elements,
   zero `onSubmit`, zero fake submissions (structurally tested).

6. **Accessibility & responsiveness.** Semantic landmarks (`header`/`nav` with
   `aria-label`, `main`, `footer`), one `h1`, `aria-labelledby` on every section,
   anchor-stable section ids (`#capabilities #runtimes #security #pricing`),
   `focus-visible:outline` states on all links, responsive grids
   (`sm:`/`md:`/`lg:` breakpoints), Tailwind v4 tokens only (`bg-background`,
   `text-muted-foreground`, `border-border`, `bg-primary`, `font-display`) — no
   new UI frameworks (AGENTS.md §33). No raster images → no missing alt text.

## Architecture Impact

- Additive presentation layer only. No kernel, capability, policy, RLS, API or
  server-function change. The page performs no database reads and no auth calls;
  it is static marketing presentation (explicitly legitimate static content, not
  a fake backend).
- Platform neutrality preserved: the site imports `@/lib/platform`
  (PLATFORM_NAME/PLATFORM_TAGLINE) and its own content modules only; it imports
  no runtime/vertical module. The runtime's name appears only as an installed-
  runtime fact in the site's own content module.
- `subscription-tiers.ts` untouched; its "no new consumers" freeze is respected.
