## Implemented

- Catalog, per-organization emission gate, exact payload-key validation, deterministic dedupe, and
  exception-isolated triggers for the source types listed in ADR-111.
- Deferred `fees.overdue` (no status/clock source) and `payment.failed` (its identified payment
  intent schema is a not-applied draft and has no failed status).
- Local SQL security/tenant/idempotency checks, a local E2E source-to-published-workflow dispatch,
  and workflow tick error span/counter instrumentation.
- Pilot enablement, rollback/kill switch, and free-tier alert guidance in the runbook.

## Validation and operational boundary

- Migration replay and WF-05 integration SQL run only in the disposable local sim-lab.
- The E2E harness requires a synthetic local school with no workflow or audit history, disables
  the organization's setting after dispatch, and retains its fixtures so append-only audit
  evidence is preserved.
- This draft does not deploy, apply SQL to hosted databases, enable the Worker route, or enable an
  organization. Production stays off (`WORKFLOWS_ENABLED` unset; no enabled organization).
- Production enablement requires Muhammad's written approval as described in the runbook.
