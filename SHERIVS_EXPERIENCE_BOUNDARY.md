# Sherivs Experience Boundary Lock

Version target: **ACTIVE-V1**
Status: **LOCKED** for Planes A–D classification. Visual redesign of Plane C/D is **not** authorized by this lock.
Executable classifier: `frontend/src/lib/experience/experience-planes.ts`
Identity gateway: `frontend/src/lib/identity/identity-gateway.ts`

## Law

Every experience surface belongs to exactly one primary plane.

| Plane | Name | Host intent | Audience |
|-------|------|-------------|----------|
| A | `public_sherivs` | sherivs.com | Company/platform visitors |
| B | `public_organization` | `{org}.sherivs.com` or custom domain | Organization public visitors |
| C | `organization_workspace` | app.sherivs.com/o/{org} | Authorized members |
| D | `sherivs_internal` | internal.sherivs.com | Sherivs operators, Jarvis, control |

Tenant host `/` is Plane B at runtime (`classifyExperiencePath(path, { tenantPublicHome: true })`). Path `/` on a platform host is Plane A.

## Canonical routing (V1 closest-safe)

| Intent | V1 route | Notes |
|--------|----------|-------|
| Sherivs public | `/` | Plane A; Command Centre unmounted |
| Sign in | `/auth` (`/login`, `/signin` aliases) | Identity gateway |
| Platform detail | `/platform` | Plane A |
| LEGACY public URL | `/coregrid` | Compatibility alias → same public home |
| Org public | tenant host `/` or `?school=` | Plane B `PublicSchoolSite` |
| Org workspace | role paths `/admin`, `/teacher`, … | Plane C; Scholar until org-prefixed rebind |
| Domain-neutral workspace | `/runtime` | Plane C when runtime ≠ Scholar |
| Sherivs internal | `/super-admin/*`, `/command-centre` | Plane D |

Target `app.sherivs.com/o/{organization}/scholar` is **DEFINED**, not yet implemented. Current Scholar paths remain top-level under Plane C.

## Contradictions locked (must not regress)

1. LOGIN → Scholar is forbidden unless membership + `runtime:scholar` resolve (`resolveIdentityGateway`).
2. Super-admin never lands on a school portal.
3. Public `/` is not Command Centre (Plane D leak closed).
4. `/platform` chrome must not label Home as Command Centre.
5. Restaurant domain remains TEST_FIXTURE (`frontend/src/lib/domain-config/restaurant.ts`), not a universal primitive.
